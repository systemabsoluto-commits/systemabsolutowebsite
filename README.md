# System Absoluto LLC — Sitio web

Landing page estática (HTML/CSS/JS) de **System Absoluto LLC**, Oklahoma City.
Instalación de cámaras de seguridad Reolink (PoE y WiFi), cerraduras y timbres inteligentes,
y mantenimiento de computadoras y servidores para empresas.

- `index.html`: versión en inglés (página principal)
- `es/index.html`: versión en español
- `css/styles.css`: estilos generales y ajustes para celular
- `js/main.js`: botón flotante de WhatsApp / llamada y formulario de cotización (envía la solicitud por WhatsApp)
- `images/`: logo, favicon, fotos de Reolink (partner) y fotos de Unsplash (licencia libre)

## Publicar en GitHub Pages

1. En el repositorio: **Settings → Pages**.
2. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Para usar el dominio propio, escribe `systemabsolutollc.com` en *Custom domain*
   y apunta los DNS del dominio a GitHub Pages.
